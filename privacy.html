Privacy Policy

Last updated: October 21, 2026

1. What this app is

Vocyth is a small personal tool that publishes short-form videos (stories, myths, puzzles and similar content, produced with AI tools) to the Vocyth YouTube channel. The OAuth application named "Vocyth" is used only by the owner of that channel, for that channel. It is not offered to the public and no other users sign in to it.

2. Google user data we access

When the owner signs in with Google, the app requests access to the owner's own YouTube account to:

  • read basic channel information;
  • upload videos and edit their metadata (title, description, tags) and publishing schedule;
  • read YouTube Analytics reports for the channel, to see how videos perform.

This data is used only to operate and improve the owner's own channel.

3. Storage

OAuth tokens and analytics data are stored only on the owner's local computer. They are not sent to any server operated by us.

4. Sharing

We do not share, sell or transfer Google user data to third parties, and we do not use it for advertising.

Vocyth's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

The app uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

6. Revoking access

Access can be revoked at any time in your Google account settings:

  • https://myaccount.google.com/permissions
  • https://security.google.com/settings/security/permissions

7. Data deletion

Because data lives only on the local computer, it is deleted by removing the stored tokens and analytics files from that computer. Once access is revoked, the stored tokens become invalid and can no longer be used to reach the YouTube account.

8. Cookies and tracking

This website does not use cookies, analytics or any other tracking.

9. Contact

For questions about this policy, contact us through the Vocyth YouTube channel.
